# SkinShift demo capture brief

This is the remaining visual-evidence step for the launch. Capture from a clean Chromium profile with no personal ChatGPT sidebar, drafts, conversations, account details, or unrelated extensions visible.

## Storyboard

Keep the final recording to roughly 15–20 seconds:

1. Show the default ChatGPT home surface for 2 seconds.
2. Open the SkinShift popup.
3. Select Nebula and hold for 3 seconds.
4. Select Neon Vice and hold for 3 seconds.
5. Select Noir Signal and hold for 3 seconds.
6. Toggle SkinShift off and on once, then finish on the clean popup with the GitHub contribution CTA visible.

Use a 16:10 or 16:9 crop. Export a lightweight `marketing/assets/demo.gif` for the README and social use, plus clean 1280×800 PNG screenshots for the Chrome Web Store listing. Remove browser chrome where practical, but keep enough context to show that this is ChatGPT.

## Safety checks

- Use only a blank or seeded public-safe ChatGPT state.
- Do not show prompts, responses, names, email addresses, account menus, private tabs, or browser extensions unrelated to SkinShift.
- Do not use Batman, GTA, Miami Vice, or other third-party franchise marks.
- Confirm that each theme is readable, the popup opens, the enabled/disabled state works, and the page returns to its normal surface after disabling.
- Review every exported frame before committing or uploading it.

The current repository contains the truthful product preview at `marketing/assets/social-preview-1280x640.png`; it is intentionally not presented as a browser recording.
